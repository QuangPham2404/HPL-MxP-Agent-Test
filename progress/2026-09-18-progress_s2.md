## Key findings

1. **Single-node co-tenant contention is absent**: heavy idle-holder +1.5%
   (4r), light co-tenant +1.1% (2r), and light/moderate 4r +22.7% *above*
   control (cross-node variance) vs controls — the multinode 3x4
   1.6-40x catastrophe does not reproduce on one node. The interference
   mechanism requires the inter-node dimension (staged comms path).
2. **The only pathological run was a pristine control** (ctrl_2r_v1):
   ruled out co-tenancy, NUMA-direction placement (same shape ran fastest
   elsewhere), PCIe links, GPU clocks, cgroup limits. Cause unresolved;
   strongest unexplained signal — needs authorized analysis and/or an
   allocation-reproduction test (relevant to exp3's "affinity is free").
3. Healthy-node phase-time variance across nodes is large (2r RNG 29-53 s;
   4r headline 128.5-157.6k GF/GPU, 22.7% spread) at n=1 per cell; no
   occupied-node run fell below the healthy band.
