closed Phase-4 stack.


The dominant interpretation is a scheduling interaction:

~~~text
separate GEMM stream
    -> exposes concurrency

factorization priority
    -> protects dependency-producing factorization work

combination 101
    -> useful overlap without delaying the LU dependency path
~~~

The exact internal implementation remains a black box; this task tests only
whether the earlier NB/chunk conclusions remain stable under the observed
scheduling regime.

The dependency review keeps N, grid/order, placement, host runtime, residency,
DGEMV, panel-broadcast policy, UCX transport/affinity, precision, and GEMM
kernel closed.

The two reopened dependencies are:

- E28: NB -> LU stream and priority policy;
- E27: U-panel chunk -> LU stream and priority policy.

NB and chunk are tested jointly because both change the readiness/overlap
conditions on which the 101 scheduling gain depends. A purely sequential
NB-then-chunk sweep could discard an NB whose best behavior occurs at another
chunk value.

### 1.3 Strategic Questions / Hypotheses

This matrix must answer:

1. Does the useful NB region remain near 2048-3072 under scheduler 101?
2. Does chunk 4 remain the best tested representative, or does another valid
   chunk become stronger under factorization priority?
3. Is there a material NB × chunk interaction under scheduler 101?
4. Do larger NB values recover enough LU performance under 101 to become
   competitive with the old 2048-3072 region?
5. Does any tested pair alter IR, memory/headroom, correctness, or iteration
   count enough to reopen an upstream residency/N dependency?
6. If no pair materially improves on NB=3072/chunk=4, can E27/E28 be reclosed
   and the campaign proceed to one fresh final full-stack confirmation?

complete fixed matrix and preserves factual evidence for later

campaign.

