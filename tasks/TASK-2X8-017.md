## 1. STRATEGIC SPECIFICATION

### 1.1 Objective

Complete the final exposed NVIDIA HPL-MxP scheduling/overlap sweep on the
retained 2x8 GAAS stack.

The only scientific variables in this task are the three supported binary
scheduling flags:

~~~text
F = --prioritize-factorization
T = --prioritize-trsm
S = --use-separate-stream-for-gemm
~~~

Run the complete 2^3 factorial exactly once, with the retained current
configuration `F=0,T=0,S=1` bracketed at the beginning and end.



leader repeat, profiling branch, or final winner confirmation is authorized
inside TASK-2X8-017.

### 1.3 Strategic Questions / Hypotheses

The factorial should answer:

1. Does factorization priority improve the current chunk-4 / NCCL readiness
   regime?
2. Does TRSM priority have a measurable main effect?
3. Is the separate GEMM stream still beneficial after the Phase-4 change from
   chunk 8 to chunk 4?
4. Do any of these controls interact materially, such that a flag's effect
   depends on the state of another flag?
5. Is the current retained control `001` already near the best scheduling
   region, or does another binary combination materially improve the full
   solver?

Prior single-node and older-regime evidence may guide interpretation later but
must not control execution.

Codex must not choose the final winner. It must execute the complete approved
matrix and preserve factual evidence for Strategic Analyst comparison.
